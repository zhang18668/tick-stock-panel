# 缠论复盘

入口为左侧导航的「缠论复盘」，路径 `/chan-review`。既有「缠论分析」继续用于输入单只股票即时画线。

1. 先同步本地股票名录和日K，然后点击「新建扫描」。可选择全部股票、当前用户自选或指定完整代码（例如 `600000.SH`），支持日线、周线。
2. 「实盘观测」在北京时间当天15:30后运行；「历史补算」按所选窗口的实际行情日期逐日推进。两类档案分开查询，历史补算不冒充当日实盘发现。
3. 按1买、2买、3买筛选，保留原始 B1/B1p、B2/B2s、B3a/B3b 子类型。日期可按首次观测日或买点落点日筛选。窗口第一天已存在的信号会提示，首次观测不代表它最早生成的日期。
4. 选择股票后，「当时结构」直接显示归档的行情、笔、线段、中枢及信号。归档版本可切换，旧图不会用当前行情重新计算。信号后续不再出现时仍保留记录。
5. 「后续走势」使用当前统一复权口径，只按日期标记历史信号；支持上一根、下一根、播放、暂停、速度和回到观测日。当前图不叠加旧口径的结构价格。周线按整周展开。
6. 「扫描任务」展示进度、缺失行情及失败原因，可取消和续跑。续跑生成关联的新任务，并校验用户、原参数、规则和行情版本；数据版本变化时请新建扫描。

扫描仅使用已同步的股票行情，不自动下载、不自动定时运行。单任务最多252个实际观测交易日，每只股票输入最多2000根日K；图下显示实际预热覆盖。股票范围来自当前名录，不能保证包含全部历史退市股或历史成分。缺行情与成功但无信号分别记录，部分覆盖会明确提示。

计算复用项目固定版本的 `chan.py`。买卖点为可能变化的形态信号。此页用于人工看图复盘，没有自动胜率统计或交易执行。

运行档案在数据目录的 `research/chan_review/`，按用户隔离。行情输入和图表快照按内容哈希保存；信号区间索引在发布时生成，分页与详情读取索引及相关股票分区。档案不会自动删除，请将该目录纳入数据备份。
