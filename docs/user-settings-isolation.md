# 用户设置隔离

多用户模式下，设置分为两类：

## 平台设置

仅管理员可以修改，继续使用平台级文件配置，以保证所有用户共享同一套行情和后台任务：

- TickFlow Key 与服务端点
- 行情数据源及插件
- 数据同步、定时任务、批处理参数
- 全局实时行情轮询
- 扩展页面和公共信号库管理

普通用户的设置页面不显示这些入口，直接调用对应写接口也会返回 `403`。

## 用户设置

写入 PostgreSQL `user_settings` 表并按 `user_id` 隔离：

- AI 服务、模型和 API Key
- 菜单顺序与隐藏项
- 自选股及选股结果列配置
- 页面刷新、展示和个人行为偏好
- 飞书、企业微信通知配置
- 新建监控规则的默认通知渠道

普通偏好保存在 JSON 字段中；AI Key、Webhook 地址及签名密钥加密后保存。加密主密钥位于运行数据目录 `data/user_data/user-settings.key`，不得提交 Git，生产备份必须同时包含该密钥，否则无法恢复已加密的用户配置。

单机模式保持原来的 `preferences.json` 和 `secrets.json` 行为。
